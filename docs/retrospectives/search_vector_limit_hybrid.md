# 벡터 검색 단독의 한계 — 막연한 질문이 드러낸 랭킹 문제

> 2026-05-29 | 분야: 검색 (retrieval)

## 증상

누구나 답을 아는 통상적인 질문에 답변이 거부되었다.

- 질문: "대마초를 하면 어떻게 되는거야?" (캘리포니아)
- 응답: "제공된 정보만으로는 답변하기 어렵습니다."

관련 법(HSC 11362.x)은 DB에 존재하고, 구체적인 질문에는 정상 답변되던 주제였다.

## 추적

**1차 — 검색 실패인가, 답변 거부인가?**

응답의 `related_law_id_list`에 **7건(=TOP_K)이 모두 채워져 있었다.** 이 리스트는 LLM 호출 이전 단계에서 채워지므로, 검색은 동작했고 LLM이 거부한 것이다.

```
검색 0건 → "관련도 낮음" 메시지 (이 경우 아님)
검색 7건 → LLM이 받음 → "이 자료로는 답변 불가" 거부  ← 실제 상황
```

**2차 — 검색된 7건을 DB에서 직접 조회**

| 조항 | 내용 | 주제 |
|---|---|---|
| Section 31 | 형법은 형사소송을 정의·규정한다 | 형법 일반 |
| Section 12 | 범죄를 처벌 가능하다 선언하는 조항들 | 처벌 일반 |
| Section 657 | 형사행위는 모독죄여도 범죄로 처벌됨 | 처벌 일반 |
| Section 658 | 선고 시 전과 반영 | 양형 |
| Section 705 | 위협된 범죄 우려가 없으면… | 절차 |
| Section 3045 | 사면된 전과 기반 선고 | 양형 |
| Section 56638 | 등급·상태 허위진술 경범죄 | 농산물 |

→ **7건 전부 대마초와 무관한 형법 총칙·절차 조항.** 대마초 실체법(HSC 11362.x)은 7위 안에 들지 못했다. LLM은 근거 없는 자료를 받고 가드레일에 따라 정상적으로 거부한 것이다. **진짜 원인은 검색 랭킹.**

**교차 검증 — 음주운전 질문으로 재현**

같은 현상이 다른 주제에서도 나타나는지 "음주운전 하면 어떻게 돼?"로 검증했다.

| 조항 | 내용 | 관련성 |
|---|---|---|
| Section 1822 | 음주·약물 운전은 주요 안전 문제 (입법 취지) | ✅ 직접 |
| Section 23578 | 23152/23153 위반 유죄 시 가중 | ✅ 직접 |
| Section 23593 | 음주운전 유죄자에 대한 법원 경고 | ✅ 직접 |
| Section 24200.8 | 주류 판매 위반 징계 | 🔶 인접 |
| Section 32553 | 주류·증류주 전용 금지 | 🔶 인접 |
| Section 31 | 형법은 형사소송을 정의한다 | ❌ 노이즈 |
| Section 3540 | "사건은 본인을 따른다" (1872년 법언) | ❌ 노이즈 |

→ 3/7이 직접 관련이라 답변은 생성됐으나 동일한 약점이 드러났다: ① 핵심 본조문(VEH 23152/23153, "음주운전은 불법이다")이 7위 안에 없고 그것을 *참조하는* 2차 조항만 검색됨. ② Section 31 같은 추상 조항이 또 노이즈로 혼입 (대마초 때와 동일).

## 원인 분석

1. **의미 무게중심 이동**: "~하면 어떻게 돼?"는 의미가 구체 주제(대마초)가 아닌 "처벌/결과"라는 추상 개념에 쏠려, 형법 총칙과 매칭된다.
2. **추상 조항의 자석 현상**: 범죄·처벌을 추상적으로 정의하는 짧은 조항이 막연한 질문마다 상위로 끌려온다.
3. **키워드 정밀 매칭 약함**: 벡터 검색은 "cannabis", "23152" 같은 정확한 명사·조문 번호를 콕 집지 못한다.

## 결정

**하이브리드 검색(Vector + BM25 키워드) 도입을 결정.** 키워드 매칭이 구체 명사·본조문을 직접 끌어올리고, 추상 총칙은 키워드 매칭이 약해 자연히 밀려난다. (보완책으로 크로스 인코더 reranker는 후속 과제)

## 배운 점

- `related_law_id_list`가 채워져도 검색 성공이 아니다. **건수가 아니라 내용을 봐야 한다.**
- 가드레일의 "답변 불가"는 버그가 아니라 올바른 동작이었다. 문제는 항상 앞단에 있을 수 있다.
- 벡터 검색은 의미 유사도에 강하고 정확한 용어 매칭에 약하다 — 법률처럼 용어가 중요한 도메인은 키워드 검색 결합이 필요하다.
