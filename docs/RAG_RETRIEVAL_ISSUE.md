# RAG 검색 품질 문제 회고 — 벡터 검색의 한계 발견

> 작성일: 2026-05-29
> 주제: 일반적인 법률 질문에 "답변 불가"가 반환되는 문제의 추적과 해결 결정

---

## 1. 문제 발생 (증상)

서비스 테스트 중, **누구나 답을 알 법한 통상적인 질문**에 답변이 거부되는 현상이 발견되었다.

- **질문**: "대마초를 하면 어떻게 되는거야?" (country_id=2, 캘리포니아)
- **응답**: "제공된 정보만으로는 답변하기 어렵습니다."

캘리포니아 대마초 관련 법(HSC 11362.x)은 DB에 분명히 존재하고, 과거 구체적인 질문에서는 정상 답변되던 주제였기에 원인 추적에 착수하였다.

---

## 2. 문제 추적 과정

### 2.1 1차 추적 — "검색 실패"인가 "답변 거부"인가?

응답에 `related_law_id_list`가 **7건(=TOP_K=7) 모두 채워져 있었다.** 이는 검색이 0건이 아니라 **7건을 검색했음에도 LLM이 답변을 거부**했다는 의미다.

```
검색 0건  → "관련도 낮음" 메시지 (이 경우 아님)
검색 7건  → LLM이 받음 → "이 자료로는 답변 불가" 거부  ← 실제 상황
```

`related_law_id_list`는 LLM 호출 이전 단계(retrieve_laws)에서 채워지므로, 7건이 나왔다는 것은 검색 자체는 동작했다는 뜻이다. → **검색 품질 또는 가드레일 문제로 범위 좁힘.**

### 2.2 2차 추적 — 검색된 7건의 실제 내용 확인

검색된 law_id 7건을 DB에서 직접 조회한 결과:

| 조항 | 내용 | 주제 |
|---|---|---|
| Section 31 | 형법은 형사소송을 정의·규정한다 | 형법 일반 |
| Section 12 | 범죄를 처벌 가능하다 선언하는 조항들 | 처벌 일반 |
| Section 657 | 형사행위는 모독죄여도 범죄로 처벌됨 | 처벌 일반 |
| Section 658 | 선고 시 전과 반영 | 양형 |
| Section 705 | 위협된 범죄 우려가 없으면… | 절차 |
| Section 3045 | 사면된 전과 기반 선고 | 양형 |
| Section 56638 | 등급·상태 허위진술 경범죄 | 농산물 |

→ **7건 전부 대마초와 무관한 형법 총칙·절차 조항이었다. 대마초 실체법(HSC 11362.x)은 7위 안에 들지 못했다.**

LLM은 대마초 정보가 없는 7건을 받고, 환각 방지 가드레일에 따라 "답변 불가"를 반환한 것이다. **즉 가드레일은 정상 작동했고, 진짜 원인은 검색(랭킹) 단계였다.**

### 2.3 교차 검증 — 음주운전 질문으로 재현

같은 현상이 다른 주제에서도 나타나는지 "음주운전 하면 어떻게 돼?"로 검증하였다.

| 조항 | 내용 | 관련성 |
|---|---|---|
| Section 1822 | 음주·약물 운전은 주요 안전 문제 (입법 취지) | ✅ 직접 |
| Section 23578 | 23152/23153 위반 유죄 시 가중 | ✅ 직접 |
| Section 23593 | 음주운전 유죄자에 대한 법원 경고 | ✅ 직접 |
| Section 24200.8 | 주류 판매(25602/25658) 위반 징계 | 🔶 인접 |
| Section 32553 | 주류·증류주 전용 금지 | 🔶 인접 |
| Section 31 | 형법은 형사소송을 정의한다 | ❌ 노이즈 |
| Section 3540 | "사건은 본인을 따른다"(1872년 법언) | ❌ 노이즈 |

→ 음주운전은 3/7이 직접 관련이라 답변은 생성되었으나, **두 가지 약점이 동일하게 드러났다:**
1. **핵심 본조문(Section 23152/23153, "음주운전은 불법이다")이 7위 안에 없음.** 그것을 *참조하는* 2차 조항만 검색됨.
2. **Section 31, 3540 같은 추상 조항이 노이즈로 또 혼입됨.** (대마초 때와 동일)

## 3. 원인 분석 (결과)

두 사례를 종합한 결론:

### 3.1 막연한 질문 → 의미 무게중심 이동
"~하면 어떻게 되는거야?"는 의미의 무게중심이 **구체 주제(대마초)가 아니라 "처벌/결과(what happens)"라는 추상 개념**에 쏠린다. 그 결과 "범죄·처벌이 무엇인가"를 정의하는 형법 총칙 조항들과 매칭된다.

### 3.2 추상 조항의 "자석(attractor)" 현상
Section 31, 12, 3540처럼 범죄·처벌을 추상적으로 정의하는 짧은 조항들은, **처벌과 관련된 막연한 질문이 들어올 때마다 반복적으로 상위에 끌려오는** 경향이 있다. 정작 구체적 실체법은 이들에게 밀려난다.

### 3.3 구체 명사·조문 번호를 콕 집지 못함
벡터 검색은 의미적 유사도는 잘 잡지만, **"cannabis", "23152" 같은 정확한 명사·조문 번호를 정밀하게 매칭하는 능력이 약하다.** 그래서 핵심 본조문이 누락된다.

→ **결론: 데이터 부재가 아니라 "벡터 검색 단독"의 랭킹 한계가 근본 원인이다.**

## 4. 해결 방법 결정

### 4.1 즉시 대응 (데모용)
질문을 구체화하면 정상 동작한다.
- ❌ "대마초를 하면 어떻게 되는거야?"
- ✅ "캘리포니아에서 성인이 대마초를 소지하면 합법이야? 한도와 처벌은?"

### 4.2 근본 해결 — 하이브리드 검색 (채택)
**의미 기반(Vector) + 키워드 기반(BM25)을 결합한 하이브리드 검색을 도입하기로 결정.**

선정 이유:
- "cannabis", "23152", "driving under the influence" 같은 **키워드가 해당 조문에 직접 매칭**되어, 의미가 두루뭉술해도 구체 명사·본조문을 정확히 끌어올린다.
- 추상 법언·총칙(31, 3540)은 키워드 매칭이 약해 자연히 순위에서 밀려난다.
- 이번에 발견한 두 가지 약점(명사 희석, 본조문 누락)을 직접 겨냥하는 처방이다.

### 4.3 보완 — Reranker (후속)
벡터로 후보를 넓게(예: TOP 30) 뽑은 뒤, 크로스 인코더로 질문과의 실제 관련성을 재평가해 재정렬한다. 노이즈 조항(추상 총칙)을 추가로 걸러내는 역할.

---

## 5. 핵심 교훈

- `related_law_id_list`가 채워져도 "검색 성공"이 아니라 **"관련 없는 문서가 채워진 것"** 일 수 있다. 건수가 아니라 내용을 봐야 한다.
- 가드레일이 "답변 불가"를 반환한 것은 버그가 아니라 **올바른 동작**이었다. 진짜 문제는 그 앞단(검색 랭킹)에 있었다.
- 벡터 검색은 만능이 아니며, 정확한 용어·법조문 매칭에는 키워드 검색(BM25) 결합이 필요하다 → **하이브리드 검색**.
